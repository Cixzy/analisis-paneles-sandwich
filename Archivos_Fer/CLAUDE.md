## Project Overview

Analysis of 3-point bending tests on sandwich composite panels with 8 different core geometries. The Python script processes raw CSV data and generates publication-quality figures for an academic paper.

All active code and data live in the **parent directory** `../` (i.e., `MaterialesCompuestos/`). This `Archivos_Fer/` folder is reserved for new data files from collaborator Fer.

## Running the Script

```bash
cd ..
python MaterialData.py
```

Output figures are saved to `../figuras/` automatically (directory is created if missing).

## Architecture: `MaterialData.py`

Single-script pipeline with these stages:

1. **Data loading** — reads `HEXAGONOS.csv` which has a 3-row header (geometry names → column names → units) followed by numeric data. Each geometry occupies 3 columns: `Tiempo (seg)`, `Fuerza (N)`, `Desplazamiento (mm)`.

2. **Geometry config dict** — a dictionary keyed by geometry name stores physical dimensions (`altura`, `ancho`, `longitud` in mm) used to convert force/displacement into stress/strain.

3. **Property calculation per geometry:**
   - Elastic zone: first ~20% of data or up to 30% of peak force
   - Failure point: `idxmax()` on force column
   - Stress/strain: 3-point bending beam theory formulas
   - Energy absorbed: trapezoidal integration (`numpy.trapz`)
   - Flexural modulus: linear regression on elastic zone
   - SEA: energy / specimen volume
   - Instantaneous stiffness: `numpy.gradient(F, d)`

4. **Figure generation** — 9 figures saved as PNG:
   - `fig1`: Force vs. Displacement (all geometries)
   - `fig2`: Stress vs. Strain (all geometries)
   - `fig3_falla_*`: Individual failure diagrams (one per geometry)
   - `fig4`: SEA bar chart
   - `fig5`: Radar chart (multi-parameter comparison)
   - `fig6`: Boxplot of force distributions
   - `fig7`: Pearson correlation heatmap
   - `fig8`: TOPSIS ranking
   - `fig9`: Instantaneous stiffness curves

## Data Format

`HEXAGONOS.csv` structure:
```
Row 1: Carrito,,,Panal,,,1_cp,...   ← geometry name every 3 columns
Row 2: Tiempo,Fuerza,Despl,Tiempo,Fuerza,Despl,...
Row 3: seg,N,mm,seg,N,mm,...
Row 4+: numeric data (quoted strings, comma-separated)
```

The 8 geometries: `Carrito`, `Panal`, `1_cp`, `2_ca`, `3_pa`, `Hexagonal`, `Panel2`, `Lluvia`.
